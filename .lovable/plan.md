# Lift Biology question generation from "Recall" to "Application & Analysis"

## Diagnosis

The exam **Biology Test 1** is generated by `supabase/functions/extract-exam-questions/index.ts`, which composes its prompt from two subject-specific blocks:

1. `getSubjectSpecificInstructions("biology", …)` in `supabase/functions/_shared/exam-extraction-prompts.ts` (line 202–204) — currently a single sentence:
   > "Write CONCISE questions. For MCQs keep options SHORT. … Marks: 1-2 (recall), 3-4 (application), 6+ (extended). Command words: State, Describe, Explain, Compare, Evaluate, Calculate."
   This wording actively encourages low-mark recall MCQs and never mentions data, graphs, tables, experiments, controlled variables, or calculations.

2. `buildBiologyInstructions(...)` in `supabase/functions/_shared/prompt-templates.ts` — used by practice generation, also recall-leaning.

3. The mark-cap block in `extract-exam-questions/index.ts` (~line 1168) caps Biology at 8 marks but says nothing about the cognitive level of those marks.

Net effect: the model defaults to "What is X?" / "Define Y" MCQs because nothing in the prompt rewards data-driven or experimental questions, and the AO framework in `getUniversalAOInstructions()` is only triggered when an uploaded paper is being deconstructed (Phase 1 talks about "the uploaded Question Paper") — not for AI-generated-from-spec exams like Biology Test 1.

## Fix — prompt engineering only, no DB or schema changes

### 1. Rewrite the Biology subject block (`exam-extraction-prompts.ts`, ~line 202)

Replace the one-liner with an OCR H420-style rubric that forces an Application-first question mix. Key rules to inject:

- **Question mix target** for Biology (and any science) at A-Level / IB / AP:
  - ≤ 25% AO1 recall (simple "state/name/define")
  - ≥ 50% AO2 application & data-handling
  - ≥ 25% AO3 analysis / evaluation / experimental critique
- **MCQ rule**: MCQs must be *stimulus-based* (graph, table, diagram, experimental setup, short data passage). Pure definition MCQs are banned for A-Level Biology.
- **Data-handling requirement**: at least one third of structured questions must reference a provided data table, graph, or experimental result and ask the student to *calculate, deduce, or interpret* it. Use the existing `bar_chart` / `data_table` chart types already supported by `getChartData` so the renderer shows them.
- **Experimental rigour requirement**: at least two questions per paper must involve experimental methodology — identifying the independent / dependent / controlled variables, evaluating a student's method, suggesting a control, justifying replicates, or commenting on validity / reliability / accuracy.
- **Mathematical precision requirement**: at least one "show that" or quantitative calculation per paper (percentage change, rate of reaction / uptake, magnification, Hardy-Weinberg, chi-squared interpretation, water potential, etc.), with answers to an appropriate number of significant figures.
- **Forbidden patterns**: "What is the definition of …", "Which of the following is …" followed by four textbook terms, single-word recall MCQs.
- **Allowed/required openers**: "The graph shows …", "A student investigated …", "Table 1 shows results from …", "Calculate the percentage increase in …", "Suggest one reason why …", "Evaluate the student's conclusion that …", "Explain the evidence in Figure 2 for …".

Mirror the same upgrade for Chemistry and Physics blocks (they have the same recall-leaning shape) so the change is consistent for the Sciences family — but keep the change minimal: only rewrite the existing strings, no new code paths.

### 2. Add a Science-family rider in `extract-exam-questions/index.ts`

Right after the `markCapInstruction` block (~line 1168) where the subject family is already detected with the regex `/biology|chemistry|physics|combined\s*science|.../`, append a parallel **`cognitiveMixInstruction`** that injects into the system prompt:

> "For A-Level / IB / AP Sciences the question set must follow this cognitive mix: ≤25% AO1 recall, ≥50% AO2 application & data-handling, ≥25% AO3 analysis/evaluation. Every MCQ must be stimulus-based. At least one third of structured questions must reference a data table or graph and require calculation or interpretation. Include at least one 'show that' or quantitative calculation. Include at least two questions on experimental methodology (variables, controls, validity, reliability). Do not generate pure-definition MCQs."

Downgrade to a softer wording at GCSE / KS3 (still application-led but with more scaffolding), and skip the rider entirely for non-science subjects so English / History / Maths flows are unchanged.

### 3. Update `buildBiologyInstructions` in `prompt-templates.ts`

Apply the same Application-first rewrite so practice quizzes generated from `/my-subjects` (which use the practice path) also stop defaulting to recall. Keep the function signature identical.

### 4. No other changes

- No database migration.
- No changes to `exam_questions`, `exam_format`, the chart renderer, marking logic, graph system, diagram suppression, or PDF export.
- No changes to the question-type whitelist — the existing types (`mcq`, `short_answer`, `extended`, `data_table`, `bar_chart`, `graph_interpretation`) already cover everything needed; we are only changing which ones the model chooses and what it puts inside them.
- The user's existing Biology Test 1 row in the database is untouched. To see the new style they regenerate (or generate a new exam) — the prompt change takes effect on the next call to `extract-exam-questions`.
